
# 🎃 Portal Halloween — Filmes e Séries de Terror

## Sobre o projeto

O **Portal Halloween** é um portal para reunir as melhores series e filmes de terror para o melhor entretenimento para este halloween. 

## Objetivo

Reunir um catálogo de Filmes e series de terror.

## Tecnologias utilizadas

- HTML5
- CSS
- JavaScript
- Git
- GitHub
- Visual Studio Code

## Páginas do portal

- **Início (`index.html`):** apresenta o portal e sugestões de filmes de terror.
- **Séries (`series.html`):** exibe sugestões de séries de terror e suspense.
- **Cadastro (`cadastro.html`):** formulário demonstrativo para registrar preferências de entretenimento.


## Como abrir o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no computador.
3. Abra o arquivo `index.html` em um navegador.
4. Use o menu do portal para acessar as páginas de séries e cadastro.

## Organização das branches

- **`main`:** versão principal e estável do projeto.
- **`develop`:** branch de integração das funcionalidades.
- **`feature/series`:** desenvolvimento da página de séries.
- **`feature/cadastro`:** desenvolvimento da página de cadastro.
- **`fix/correcao`:** correção do texto de destaque e prática de resolução de conflitos.

## Estratégia de integração

As funcionalidades são desenvolvidas em branches separadas e integradas à `develop` por meio de Pull Requests. Após a revisão e integração das funcionalidades, a `develop` é integrada à `main` por outro Pull Request.

A correção de conflito é realizada localmente entre as branches `fix/correcao` e `develop`.

## Histórico de versões

- **`v0.1.0` — Versão inicial:** estrutura inicial do portal, com `index.html`, `Readme.md` e `.gitignore`.
- **`v1.0.0` — Portal Halloween completo:** páginas de início, séries e cadastro, com a correção integrada.
